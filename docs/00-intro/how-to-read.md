# 이 책을 읽는 법

> 이 책은 삼성전자와 관련 없는 비공식 가이드입니다. 최신 정보는 [공식 채용 사이트](https://www.samsung-dsrecruit.com)에서 확인하세요.

## 이렇게 읽으세요

1. **반도체가 처음이라면** [반도체 산업 한눈에 보기](semiconductor-overview.md)부터 읽으세요.
2. **직무를 아직 못 정했다면** [3부. 나에게 맞는 직무 찾기](../03-job-matching/index.md)로 가세요.
3. **직무를 정했다면** 2부에서 해당 직무 장을 열고 학습 로드맵을 따라가세요.

## 각 직무 장의 구성

![직무별 4단계 학습 로드맵](../assets/figures/roadmap-4steps.svg)

모든 직무 장은 같은 순서로 되어 있어 비교하며 읽기 쉽습니다.
무슨 일을 하나 → 필요한 역량 → 학습 로드맵 → 추천 자료 → 프로젝트 → 자격증·교육 → 자소서·면접 → 체크리스트

## 정보의 기준

- 각 장 상단에 **확인 기준일**을 적었습니다. 채용 절차와 복리후생은 바뀔 수 있습니다.
- 사업부명·직무명 같은 사실 정보 외의 설명은 모두 저자가 직접 쓴 해설입니다.
