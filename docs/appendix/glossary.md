# 용어사전

> 책에 자주 나오는 용어를 가나다순으로 정리했습니다. 영어 약어는 뒤쪽에 따로 모았습니다.

## 한글 용어

| 용어 | 설명 |
|---|---|
| 공정 노드 | 공정 세대를 부르는 이름 (예: 3nm). 숫자가 작을수록 최신 세대 |
| 공핍층 | PN 접합에서 전하 운반자가 거의 없는 영역 |
| 교호작용 | 실험에서 두 요인이 함께 바뀔 때 생기는 추가 효과 |
| 기판 | 칩을 올려 외부와 연결하는 판 |
| 노광 (포토) | 빛으로 웨이퍼에 회로 패턴을 새기는 공정 |
| 누설 전류 | 꺼져 있어야 할 소자에서 새는 전류 |
| 다이 | 웨이퍼에서 잘라 낸 칩 하나 |
| 대역폭 | 단위 시간에 주고받을 수 있는 데이터 양 |
| 대리 모델 | 느린 시뮬레이션을 빠르게 흉내 내는 예측 모델 |
| 도핑 | 반도체에 불순물을 넣어 전기적 성질을 바꾸는 것 |
| 문턱전압 | 트랜지스터가 켜지기 시작하는 전압 |
| 미세화 | 소자를 더 작게 만드는 것 |
| 밴드갭 | 전자가 전도대로 올라가는 데 필요한 에너지 |
| 범프 | 칩과 기판을 연결하는 작은 금속 돌기 |
| 선택비 | 식각할 때 깎을 막과 남길 막이 깎이는 속도의 비 |
| 수율 | 만든 칩 중 정상 칩의 비율 |
| 식각 | 필요 없는 부분을 깎아 내는 공정 |
| 신뢰성 | 오래, 극한 조건에서도 정상 동작하는 능력 |
| 웨이퍼 | 반도체 칩을 만드는 얇은 실리콘 원판 |
| 웨이퍼맵 | 웨이퍼 위 칩별 검사 결과를 지도처럼 표시한 것 |
| 위상 여유 | 증폭기 피드백 회로의 안정성 지표 |
| 유틸리티 | 공장 가동에 필요한 전기·물·가스·공기 |
| 이온 주입 | 불순물 이온을 웨이퍼에 쏘아 넣는 공정 |
| 인터포저 | 여러 칩을 나란히 연결하는 중간 기판 |
| 적층 | 셀이나 칩을 위로 쌓는 것 |
| 전공정 | 웨이퍼 위에 회로를 만드는 공정 (팹 공정) |
| 증착 | 웨이퍼 위에 얇은 막을 쌓는 공정 |
| 초순수 | 불순물을 거의 없앤 매우 깨끗한 물 |
| 칩렛 | 큰 칩을 기능별 작은 칩으로 나눠 만든 뒤 연결하는 방식 |
| 클린룸 | 먼지를 극도로 줄인 생산 공간 |
| 패키지 | 칩을 보호하고 외부와 연결하는 구조 |
| 팹 | 반도체 웨이퍼 생산 공장 |
| 팹리스 | 설계만 하고 생산은 외부에 맡기는 기업 |
| 파운드리 | 다른 회사가 설계한 칩을 생산하는 사업 |
| 플라즈마 | 기체가 이온과 전자로 나뉜 상태. 식각·증착에 쓰임 |
| 후공정 | 웨이퍼 이후 패키징과 테스트 단계 |
| 휨 (워피지) | 열이나 응력으로 기판·패키지가 휘는 현상 |

## 영어 약어

| 약어 | 풀이 | 설명 |
|---|---|---|
| ALD | Atomic Layer Deposition | 원자층 단위로 막을 쌓는 증착 |
| BER | Bit Error Rate | 통신에서 비트가 틀리는 비율 |
| CMP | Chemical Mechanical Polishing | 화학·기계적으로 표면을 평탄화 |
| CVD | Chemical Vapor Deposition | 기체 반응으로 막을 쌓는 증착 |
| DFT | Density Functional Theory | 원자 수준 물성을 계산하는 방법 |
| DOE | Design of Experiments | 실험계획법 |
| DRAM | Dynamic Random Access Memory | 휘발성 메인 메모리 |
| EUV | Extreme Ultraviolet | 극자외선 노광 |
| FEM | Finite Element Method | 유한요소법 |
| FTL | Flash Translation Layer | NAND를 디스크처럼 쓰게 해 주는 펌웨어 계층 |
| GAA | Gate-All-Around | 게이트가 채널을 사방에서 감싸는 트랜지스터 |
| HBM | High Bandwidth Memory | DRAM을 쌓아 대역폭을 높인 메모리 |
| HVAC | Heating, Ventilation, Air Conditioning | 공조 설비 |
| IP | Intellectual Property (설계 블록) | 재사용 가능한 회로 설계 블록 |
| MES | Manufacturing Execution System | 생산 실행 시스템 |
| MPW | Multi-Project Wafer | 여러 설계를 한 웨이퍼에 모아 만드는 시제작 |
| NAND | NAND Flash | 비휘발성 저장 메모리 |
| NPU | Neural Processing Unit | AI 연산 전용 프로세서 |
| OSAT | Outsourced Semiconductor Assembly and Test | 외주 조립·테스트 기업 |
| PDK | Process Design Kit | 공정별 설계 키트 |
| PLL | Phase-Locked Loop | 클럭을 만드는 회로 |
| PVD | Physical Vapor Deposition | 물리적 방식의 증착 |
| SCM | Supply Chain Management | 공급망 관리 |
| SoC | System on Chip | 여러 기능을 한 칩에 통합한 반도체 |
| SPC | Statistical Process Control | 통계적 공정관리 |
| TCAD | Technology CAD | 공정·소자 시뮬레이션 |
| TSV | Through-Silicon Via | 실리콘 관통 전극 |
