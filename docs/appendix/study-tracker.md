## 지원 전 최종 점검

- [ ] 직무 장의 지원 전 체크리스트를 모두 확인했다
- [ ] 포트폴리오(저장소, 보고서)를 정리했다
- [ ] 프로젝트를 3분, 1분 버전으로 설명할 수 있다
- [ ] 에세이 초안을 다른 사람에게 보여주고 피드백을 받았다
- [ ] 반도체 공통 상식(8대 공정, 메모리와 시스템반도체 차이)을 설명할 수 있다
- [ ] 최신 공고에서 전형과 일정을 확인했다
