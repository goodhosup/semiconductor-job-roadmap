# 흥미로 찾는 자가진단

> 전공은 "할 수 있는 것"을, 흥미는 "오래 할 수 있는 것"을 알려줍니다. 두 가지가 겹치는 직무가 가장 좋은 출발점입니다.

## 1단계: 어떤 문제를 풀 때 즐거운가

아래 문장 중 "나 같다"고 느끼는 것에 모두 체크하세요.

**A. 만드는 사람**

- [ ] 무언가를 처음부터 설계해서 동작하게 만들 때 가장 뿌듯하다
- [ ] 회로도나 코드를 보면 "더 좋게 만들 수 있을 것 같다"는 생각이 든다
- [ ] 정해진 조건 안에서 최적의 답을 찾는 퍼즐이 즐겁다

**B. 원인을 찾는 사람**

- [ ] 문제가 생기면 "왜 그랬을까"를 끝까지 파고든다
- [ ] 데이터나 그래프에서 이상한 점을 찾는 것이 재미있다
- [ ] 실험을 설계하고 결과를 해석하는 과정이 좋다

**C. 현장에서 움직이는 사람**

- [ ] 책상보다 현장에서 직접 보고 만지는 것이 좋다
- [ ] 장비나 기계가 어떻게 돌아가는지 궁금하다
- [ ] 문제가 생기면 빠르게 판단하고 조치하는 편이다

**D. 수식과 모델을 다루는 사람**

- [ ] 물리 현상을 수식으로 표현하는 것이 재미있다
- [ ] 시뮬레이션이나 알고리즘으로 결과를 예측해 보는 것이 좋다
- [ ] 논문을 읽고 재현해 보는 것에 거부감이 없다

**E. 사람과 숫자를 연결하는 사람**

- [ ] 여러 사람의 의견을 조율해 결론을 내는 역할을 자주 맡는다
- [ ] 시장, 고객, 돈의 흐름에 관심이 많다
- [ ] 복잡한 내용을 한 장으로 정리해 설명하는 것을 잘한다

**F. 지키는 사람**

- [ ] 규칙과 기준을 정확히 지키는 것이 중요하다고 생각한다
- [ ] 위험을 미리 예상하고 대비하는 편이다
- [ ] 환경이나 안전 문제에 관심이 많다

## 3단계: 전공과 겹쳐 보기

1. [전공별 직무 매트릭스](major-matrix.md)에서 내 전공으로 가능한 직무를 적는다
2. 이 장에서 나온 직무와 겹치는 것을 찾는다
3. 겹치는 직무가 1~3개라면 그 직무 장의 학습 로드맵 1단계를 2주 동안 해 본다
4. 해 보고 재미있으면 계속, 아니면 다음 후보로 넘어간다

> 직무 선택은 한 번에 끝나지 않습니다. 짧게 해 보고 판단하는 것이 오래 고민하는 것보다 정확합니다.
