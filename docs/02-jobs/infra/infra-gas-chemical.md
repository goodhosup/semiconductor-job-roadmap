# 인프라기술(Gas/Chemical)

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/complex/gas_chemical.php>

## 1. 이 직무는 무슨 일을 하나

반도체 공정에는 수백 종의 **가스와 화학 약품**이 쓰입니다. 그중에는 독성·가연성·부식성이 강한 물질도 많습니다. 이 직무는 **가스·화학물질을 공장 전체에 순도 높게, 안전하게, 끊김 없이 공급하는 시스템을 설계·개발·유지보수하는 일**입니다.

| 분야 | 다루는 것 |
|---|---|
| **특수 가스** | 공정용 가스의 저장, 공급, 순도 관리, 누출 감지 |
| **벌크 가스** | 질소, 산소, 아르곤 같은 대량 가스 공급 |
| **화학 약품** | 세정·식각용 약품의 저장, 혼합, 공급 |
| **배기·처리** | 사용 후 가스의 정화 설비(스크러버) 연계 |
| **안전** | 누출 감지, 비상 차단, 위험성 평가 |

### 하루 업무 예시

- 오전: 가스 공급 시스템 압력·순도 모니터링
- 점심 후: 신규 공정 가스 도입에 따른 공급 설비 설계 검토
- 오후: 약품 공급 배관 정기 점검과 누출 감지 센서 점검
- 저녁 전: 위험성 평가 회의

## 2. 필요한 역량 지도

| 구분 | 역량 | 어느 정도까지 |
|---|---|---|
| 전공지식 | 화학공학 (단위 조작, 유체 수송) | 배관 압력 손실, 펌프·압축기 선정 |
| 전공지식 | 화학, 물리화학 | 물질의 반응성, 상평형 |
| 전공지식 | 공정안전 | 위험성 평가(HAZOP 등), 독성·가연성 물질 관리 |
| 전공지식 | 재료 (부식) | 배관 재질 선정 |
| 툴·실무 스킬 | P&ID 도면 | 배관·계장 도면 읽기와 작성 |
| 툴·실무 스킬 | 데이터 분석 | 공급 시스템 운영 데이터 분석 |
| 소프트 스킬 | 안전 우선의 판단 | 원칙을 지키는 태도 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

- 반도체 공정별로 쓰이는 대표 가스·약품 정리
- 화학물질 안전 정보(MSDS) 읽는 법

### 2단계: 기본기 (3~4개월)

- 유체 수송: 배관 설계, 압력 손실 계산
- 공정안전: 위험성 평가 기법(HAZOP, What-if)
- P&ID 도면 읽기 연습

### 3단계: 심화 (3~6개월)

- 고순도 가스·약품 공급 기술 (오염 방지, 순도 측정)
- 화학물질 관련 법규 기초 (화학물질관리법, 산업안전보건법)
- 관련 자격증 준비

### 4단계: 포트폴리오 (2~3개월)

- 가상의 가스 공급 시스템 설계와 위험성 평가 보고서

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 화공 | 단위 조작, 유체역학 교재 | 기본 |
| 공정안전 | 공정안전관리(PSM) 관련 공공기관 자료 | 위험성 평가 |
| 법규 | 화학물질관리법, 산업안전보건법 해설 자료 | 공공기관 무료 자료 |
| 도면 | P&ID 입문 자료 | 실무 기초 |

## 5. 직접 해보는 프로젝트

1. **공정 가스·약품 정리표** (입문): 공정별 사용 물질과 위험성
2. **가스 공급 배관 설계** (기본기): 유량, 압력 손실, 재질 선정
3. **HAZOP 연습** (심화): 가상 약품 공급 시스템의 위험 요소와 대책

## 6. 자격증·교육 프로그램

- **화공기사**, **위험물산업기사**, **가스기사**, **화공안전기술사(장기 목표)** 등이 연관됩니다.
- 공정안전 관련 교육 수료도 좋은 근거입니다.

## 7. 자기소개서·면접에서 보여주는 법

- **안전과 효율 사이의 판단**: 안전 원칙을 지킨 경험
- **화공 지식과 반도체 공장 연결**
- **면접 단골 질문 대비**: 독성 가스가 누출되면 어떻게 대응하나, 고순도 공급이 왜 중요한가, HAZOP이란 무엇인가

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "공정과 상관없는 지원 업무다" → 가스·약품의 순도와 공급 안정성이 수율에 직접 영향을 줍니다.

**지원 전 체크리스트**

- [ ] 반도체 공정에 쓰이는 대표 가스·약품을 말할 수 있다
- [ ] 배관 압력 손실을 계산할 수 있다
- [ ] 위험성 평가 기법 하나를 설명할 수 있다
- [ ] 관련 기사 자격증을 준비했거나 취득했다
