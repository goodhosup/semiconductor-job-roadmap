# 인프라기술(건설/Facility/전기)

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/complex/facility.php>

## 1. 이 직무는 무슨 일을 하나

반도체 공장은 거대한 정밀 기계와 같습니다. 먼지 하나 없는 클린룸, 끊기지 않는 전력, 극도로 깨끗한 물(초순수), 일정한 온도와 습도가 24시간 유지돼야 합니다. 이 직무는 **공장 건물과 그 안의 유틸리티 시스템을 기획·설계·시공·운영하는 일**입니다.

| 분야 | 다루는 것 |
|---|---|
| **건축·토목** | 공장 건물 기획, 설계, 시공 관리, 감리, 구조 안전 |
| **전기** | 수변전 설비, 전력 공급망, 비상 전원, 전력 품질 |
| **HVAC·클린룸** | 공조(온도·습도·청정도), 클린룸 기류 |
| **초순수(UPW)** | 웨이퍼 세정에 쓰는 고순도 물 생산과 공급 |
| **기계 설비** | 냉각수, 압축 공기, 배관 |

### 하루 업무 예시

- 오전: 신규 라인 공사 현장의 공정률과 안전 점검
- 점심 후: 클린룸 공조 설비의 에너지 절감 방안 검토
- 오후: 전력 설비 이상 이력 분석과 예방 보수 계획
- 저녁 전: 설계사·시공사와 도면 변경 협의

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

- 반도체 공장(팹)의 구조 조사: 클린룸, 하부 유틸리티 층, 지원 시설
- 클린룸 청정도 등급과 유지 원리

### 2단계: 기본기 (3~4개월)

- 자기 전공 분야의 설비를 반도체 공장 관점에서 다시 공부
    - 전기: 대용량 수변전, 무정전 전원, 전력 품질(순간 정전의 영향)
    - 기계: 공조 부하 계산, 냉동 사이클, 클린룸 기류
    - 건축: 대형 공장 구조, 진동 관리
- 관련 기사 자격증 준비 시작

### 3단계: 심화 (3~6개월)

- 에너지 효율과 탄소 저감 기술 (폐열 회수, 고효율 설비)
- 설비 운영 데이터 분석으로 이상 감지
- 대형 건설 프로젝트 관리 (일정, 원가, 품질, 안전)

### 4단계: 포트폴리오 (2~3개월)

- 설계 프로젝트나 현장 실습 경험 정리
- 에너지 절감 아이디어 제안서

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 클린룸 | 클린룸 공학 입문서 | 공조·청정도 |
| 전기 | 전기설비기술기준, 전력공학 교재 | 기사 준비와 겸함 |
| 공조 | 공기조화 교재 | 부하 계산 |
| 건설 | 건설관리 교재 | 일정·원가 |
| 에너지 | 에너지 관련 공공기관 자료 | 효율·탄소 |

## 5. 직접 해보는 프로젝트

1. **클린룸 공조 부하 계산** (기본기): 가상 클린룸의 냉방 부하와 풍량 계산
2. **수변전 설비 단선도 작성** (기본기): 가상 공장의 전력 공급 구조 설계
3. **에너지 절감 제안서** (심화): 공장 유틸리티 에너지 사용 구조 분석과 절감안

## 6. 자격증·교육 프로그램

이 직무는 다른 직무보다 **국가기술자격의 연관성이 높은 편**입니다.

- 전기: **전기기사**, 전기공사기사
- 기계: **공조냉동기계기사**, 일반기계기사, 에너지관리기사
- 건축·토목: **건축기사**, 토목기사, 건설안전기사
- 수처리: 수질환경기사

## 7. 자기소개서·면접에서 보여주는 법

- **"끊기지 않는 공급"의 중요성 이해**: 순간 정전이나 공조 이상이 생산에 어떤 피해를 주는지
- **현장 경험**: 실습, 인턴, 현장 견학에서 배운 점
- **면접 단골 질문 대비**: 클린룸 청정도 유지 원리, 반도체 공장에 초순수가 필요한 이유, 에너지 절감 방안

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "반도체 회사에서는 반도체 전공만 필요하다" → 건축, 토목, 전기, 기계, 환경 전공이 공장 인프라를 책임집니다.
- "건설이 끝나면 일이 없다" → 운영, 증설, 에너지 효율 개선이 계속 이어집니다.

**지원 전 체크리스트**

- [ ] 반도체 공장의 구조와 유틸리티 종류를 설명할 수 있다
- [ ] 자기 전공 설비가 반도체 공장에서 왜 중요한지 말할 수 있다
- [ ] 관련 기사 자격증을 준비했거나 취득했다
