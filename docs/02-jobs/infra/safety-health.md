# 안전보건

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/complex/safety_health.php>

## 1. 이 직무는 무슨 일을 하나

**일하는 사람이 다치거나 병들지 않도록 기준을 세우고, 현장을 점검하고, 사고를 예방하는 일**입니다. 반도체 공장에는 고압 전기, 독성 가스, 화학 약품, 대형 장비, 건설 공사 현장이 함께 있어 안전보건 관리가 매우 중요합니다. 공식 소개는 법규 준수 기준 수립, 위험작업 감리, 사고 예방을 언급합니다.

| 분야 | 다루는 것 |
|---|---|
| **안전** | 위험작업 관리, 작업 허가, 설비 안전 인증 |
| **보건** | 작업환경 측정, 유해물질 노출 관리, 건강 관리 |
| **방재** | 화재·폭발·누출 대응, 비상 훈련 |
| **법규·인허가** | 산업안전보건법, 중대재해처벌법 대응 |
| **안전문화** | 교육, 캠페인, 협력사 안전 관리 |

### 하루 업무 예시

- 오전: 오늘 예정된 위험작업(고소 작업, 화기 작업) 허가 검토
- 점심 후: 신규 장비 반입 전 안전성 검토
- 오후: 현장 순회 점검, 개선 사항 기록
- 저녁 전: 아차사고 사례 분석과 재발 방지 대책 회의

| 전공지식 | 산업보건 | 유해인자, 작업환경 측정, 노출 기준 |
| 전공지식 | 관련 법규 | 산업안전보건법, 중대재해처벌법의 핵심 |

| 소프트 스킬 | 원칙을 지키는 소통 | 일정 압박 속에서도 안전 기준을 설득 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

- 반도체 공장의 주요 위험 요인 정리 (전기, 가스, 화학, 기계, 건설)
- 산업안전보건법의 기본 구조

### 2단계: 기본기 (3~4개월)

- 위험성 평가 방법과 실습
- 사고 원인 분석 기법 (하인리히 법칙, 근본 원인 분석)
- **산업안전기사** 준비

### 3단계: 심화 (3~6개월)

- 중대재해처벌법과 안전보건 관리 체계
- 화학물질 위험성, 공정안전관리(PSM)
- 작업환경 측정과 보건 관리

### 4단계: 포트폴리오 (2~3개월)

- 가상 현장의 위험성 평가 보고서와 개선안
- 안전 관련 실습·인턴·봉사 경험 정리

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 안전 | 산업안전기사 교재, 안전공학 교재 | 기본 |
| 법규 | 고용노동부·안전보건공단 자료 | 무료 |
| 사례 | 안전보건공단 재해 사례 자료 | 사고 원인 공부 |

## 5. 직접 해보는 프로젝트

1. **재해 사례 분석 노트** (기본기): 공개 사고 사례 5건의 원인과 예방 대책 정리
2. **위험성 평가 실습** (기본기): 실험실이나 가상 작업의 위험성 평가표 작성
3. **안전문화 개선 제안** (심화): 협력사 안전 관리 개선 방안

## 6. 자격증·교육 프로그램

이 직무는 **자격증의 연관성이 매우 높습니다.**

- **산업안전기사**, **건설안전기사**, **산업위생관리기사**, **소방설비기사**, **위험물산업기사**
- 장기 목표로 안전·보건 분야 기술사

## 7. 자기소개서·면접에서 보여주는 법

- **원칙을 지킨 경험**: 압박 속에서도 기준을 지키고 설득한 사례
- **예방 관점**: 사고가 난 뒤가 아니라 나기 전에 무엇을 할 것인가
- **면접 단골 질문 대비**: 하인리히 법칙, 반도체 공장의 주요 위험 요인, 현장 작업자가 안전 수칙을 무시하면 어떻게 하나

## 8. 흔한 오해와 체크리스트

- "점검만 하는 직무다" → 안전 체계 설계, 법규 대응, 안전문화까지 책임지는 전문 직무입니다.

**지원 전 체크리스트**
