# 영업마케팅

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/businessMarketing.php>

## 1. 이 직무는 무슨 일을 하나

반도체는 대부분 일반 소비자가 아니라 **스마트폰·PC·서버·자동차를 만드는 기업**에 팔립니다(B2B). 영업마케팅은 **고객사와 시장을 이해하고, 어떤 제품을 누구에게 얼마에 얼마나 팔지 전략을 세우고 실행하는 일**입니다.

| 하는 일 | 설명 |
|---|---|
| 시장 분석 | 응용처(모바일, 서버, 자동차 등)별 수요와 경쟁 동향 분석 |
| 제품 기획 지원 | 고객 요구를 개발 조직에 전달해 차세대 제품 방향에 반영 |
| 거래선 관리 | 주요 고객사와의 관계, 계약, 가격 협상 |
| 판매 전략 | 지역·고객·제품별 판매 계획과 실행 |
| 기술 영업 | 고객사 엔지니어와 기술 사양을 맞추는 일 |

### 하루 업무 예시

- 오전: 해외 고객사와 화상 회의, 다음 분기 구매 계획 확인
- 점심 후: 시장 조사 자료로 응용처별 수요 전망 업데이트
- 오후: 개발팀과 고객 요구 사양 검토 회의
- 저녁 전: 가격 협상 전략 보고서 작성

## 2. 필요한 역량 지도

| 구분 | 역량 | 어느 정도까지 |
|---|---|---|
| 전공지식 | 마케팅, 경영전략, 경제학 | B2B 마케팅, 산업 구조 분석 |
| 전공지식 | 반도체 산업·제품 이해 | 메모리·시스템반도체·파운드리 사업 모델과 주요 제품 |
| 전공지식 | 기술 기초 (이공계라면 강점) | 제품 사양을 이해하고 고객과 대화할 수준 |
| 툴·실무 스킬 | 데이터 분석 (Excel, SQL, BI 도구) | 시장 데이터를 정리하고 시사점 도출 |
| 툴·실무 스킬 | 외국어 | 해외 고객과 업무가 가능한 영어, 추가 외국어는 강점 |
| 소프트 스킬 | 협상, 설득, 관계 관리 | 이해관계가 다른 상대와 합의 이끌기 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **반도체 산업의 구조와 돈의 흐름을 이해한다.**

- 반도체 가치사슬과 주요 기업의 역할 (팹리스, 파운드리, 종합반도체기업, 장비·소재)
- 메모리 가격 사이클의 원리

### 2단계: 기본기 (3~4개월)

목표: **산업 리포트를 읽고 자기 의견을 쓸 수 있다.**

- 증권사 산업 리포트, 기업 IR 자료 꾸준히 읽기
- 응용처별 수요 동인 정리: 스마트폰 출하량, 데이터센터 투자, AI 서버, 자동차 전장화
- 경쟁 구도 분석 프레임워크 (5 Forces, SWOT)

### 3단계: 심화 (3~6개월)

목표: **데이터로 전략을 제안할 수 있다.**

- 공개 데이터로 시장 전망 모델 만들어 보기 (응용처별 수요 × 탑재량)
- 가상의 고객사를 정해 제품 제안서 작성
- 비즈니스 영어: 이메일, 회의, 발표 연습

### 4단계: 포트폴리오 (2~3개월)

- 반도체 시장 분석 보고서 1편 (데이터, 근거, 전략 제안 포함)
- 공모전·학회 활동·인턴 경험을 성과 중심으로 정리

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 산업 이해 | 반도체 산업 입문서 (국내 출간 다수) | 비전공자 친화적 |
| 시장 | 증권사 반도체 리포트, 기업 IR·실적 발표 자료 | 무료 공개 |
| 뉴스 | 전자·IT 전문 매체 | 매일 읽기 |
| 마케팅 | B2B 마케팅 교재 | 산업재 마케팅 |
| 외국어 | 비즈니스 영어 강의, 공인 어학 성적 | 지원 요건은 공고 확인 |

## 5. 직접 해보는 프로젝트

1. **응용처별 메모리 수요 전망** (심화): 스마트폰·PC·서버 출하량과 기기당 탑재량으로 수요 추정
2. **경쟁사 비교 분석** (기본기): 공개 IR 자료로 주요 반도체 기업의 사업 구조 비교
3. **가상 고객 제안서** (심화): 특정 고객(예: 자동차 회사)에게 맞는 제품 조합과 가치 제안
4. **반도체 뉴스 주간 브리핑** (입문): 매주 주요 뉴스 3개를 요약하고 시사점 작성

## 6. 자격증·교육 프로그램

- 어학 성적은 공고의 지원 요건을 꼭 확인하세요.
- 무역·마케팅 관련 자격(국제무역사 등)은 보조적인 근거가 될 수 있습니다.

## 7. 자기소개서·면접에서 보여주는 법

- **산업에 대한 자기 관점**: "요즘 반도체 시장을 어떻게 보는가"에 근거 있는 답
- **설득·협상 경험**: 구체적인 상황, 상대의 이해관계, 나의 전략, 결과
- **이공계라면 기술 이해를 강점으로**: 사양을 이해하는 영업이 고객에게 신뢰를 얻는 이유
- **면접 단골 질문 대비**: 메모리 가격이 오르내리는 이유, 파운드리 사업 모델, 고객사 한 곳을 골라 분석해 보라

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "말만 잘하면 된다" → 데이터 분석과 기술 이해가 뒷받침되어야 합니다.
- "문과만 지원한다" → 이공계 지원자도 많고, 기술 영업 성격의 업무도 있습니다.

**지원 전 체크리스트**

- [ ] 반도체 가치사슬과 주요 기업의 역할을 설명할 수 있다
- [ ] 메모리 가격 사이클을 설명할 수 있다
- [ ] 시장 분석 보고서를 한 편 이상 써 봤다
- [ ] 영어로 회의와 이메일이 가능하다
