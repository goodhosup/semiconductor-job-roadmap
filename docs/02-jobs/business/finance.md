# 경영지원(재무)

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/fieldCommon/finance.php>

## 1. 이 직무는 무슨 일을 하나

**회사의 돈이 어떻게 들어오고 나가는지 기록하고(회계), 돈을 어디에 쓸지 판단을 돕고(재무), 위험을 관리하는 일**입니다. 반도체는 공장 하나에 막대한 투자가 들어가는 산업이라, 투자 판단과 원가 관리가 특히 중요합니다.

| 분야 | 하는 일 |
|---|---|
| 회계 | 거래 기록, 결산, 재무제표 작성 |
| 원가 관리 | 제품별 원가 계산, 원가 절감 분석 |
| 경영 분석·계획 | 사업 실적 분석, 예산 수립, 투자 타당성 검토 |
| 자금·리스크 | 자금 조달과 운용, 환율·금리 위험 관리 |
| 세무 | 국내외 세금 신고와 대응 |

### 하루 업무 예시

- 오전: 월말 결산 데이터 점검
- 점심 후: 신규 설비 투자안의 경제성 분석
- 오후: 사업부 실적 보고 자료 작성
- 저녁 전: 환율 변동이 손익에 미친 영향 분석

## 2. 필요한 역량 지도

| 구분 | 역량 | 어느 정도까지 |
|---|---|---|
| 전공지식 | 회계원리, 중급회계 | 재무제표를 읽고 작성 원리를 설명 |
| 전공지식 | 원가회계, 관리회계 | 제조원가 계산, 손익분기점 분석 |
| 전공지식 | 재무관리 | NPV, IRR, 자본비용 |
| 전공지식 | 세법 기초 | 법인세 개념 |
| 툴·실무 스킬 | Excel (함수, 피벗, 재무 모델링) | 투자 분석 모델을 직접 만들 수준 |
| 툴·실무 스킬 | 데이터 분석 (SQL, Python 선택) | 대량 데이터 처리 |
| 소프트 스킬 | 정확성, 설명력 | 숫자의 의미를 경영진이 이해하게 설명 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

- 회계원리 복습, 재무상태표·손익계산서·현금흐름표의 관계
- 반도체 기업의 실제 재무제표를 내려받아 읽어 보기 (공시 시스템)

### 2단계: 기본기 (3~4개월)

- 원가회계: 고정비와 변동비, 감가상각이 반도체 기업 원가에서 큰 이유
- 재무관리: 현금흐름 할인(DCF), NPV·IRR 계산
- Excel로 간단한 투자 분석 모델 만들기

### 3단계: 심화 (3~6개월)

- 반도체 기업 재무 분석: 매출총이익률, 설비투자 규모, 감가상각비 추이
- 환율·금리 위험과 헤지 개념
- 관심 분야 자격증 준비 (아래 6번 참고)

### 4단계: 포트폴리오 (2~3개월)

- 반도체 기업 재무 분석 보고서
- 가상의 공장 투자안 경제성 분석 모델

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 회계 | 학부 회계원리·중급회계 교재 | 기본 |
| 재무 | 학부 재무관리 교재 | NPV, IRR |
| 실전 | 전자공시시스템(DART)의 반도체 기업 사업보고서 | 무료 |
| Excel | 재무 모델링 강의 | 실무형 |

## 5. 직접 해보는 프로젝트

1. **반도체 기업 재무제표 비교** (기본기): 두 기업의 5년간 수익성·투자 지표 비교
2. **공장 투자 경제성 분석** (심화): 투자비, 감가상각, 예상 매출로 NPV·IRR 계산과 민감도 분석
3. **메모리 가격 변동과 이익 관계 분석** (심화): 가격 사이클과 영업이익률 추이 비교

## 6. 자격증·교육 프로그램

- **재경관리사**, **회계관리 1급**, **전산회계·세무** 자격은 기본기 증명에 쓰입니다.
- **CPA(공인회계사)**, **AICPA**, **세무사**는 준비 기간이 길지만 강력한 근거가 됩니다.
- 자격증이 많다고 유리한 것은 아니므로, 분석 경험과 함께 균형 있게 준비하세요.

## 7. 자기소개서·면접에서 보여주는 법

- **숫자 뒤의 의미를 말하기**: "영업이익률이 떨어졌다"가 아니라 "가격 하락과 감가상각비 증가가 겹쳤기 때문"
- **반도체 산업 특성 이해**: 대규모 투자, 경기 사이클, 높은 고정비
- **면접 단골 질문 대비**: 감가상각의 의미, 현금흐름표가 중요한 이유, NPV와 IRR의 차이

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "회계 자격증만 있으면 된다" → 산업과 사업을 이해하고 숫자로 해석하는 능력이 더 중요합니다.
- "반도체 기술은 몰라도 된다" → 원가와 투자를 분석하려면 공정과 제품의 기본은 알아야 합니다.

**지원 전 체크리스트**

- [ ] 반도체 기업 재무제표를 직접 읽고 분석해 봤다
- [ ] NPV·IRR을 Excel로 계산할 수 있다
- [ ] 반도체 산업에서 감가상각비가 큰 이유를 설명할 수 있다
