# 인사

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/fieldCommon/managementHR.php>

## 1. 이 직무는 무슨 일을 하나

**회사에 필요한 사람을 뽑고, 기르고, 공정하게 평가·보상하고, 일하기 좋은 조직을 만드는 일**입니다. 반도체 산업은 기술 인재 확보 경쟁이 치열해서 인사의 전략적 역할이 큽니다.

| 분야 | 하는 일 |
|---|---|
| 채용 | 인력 계획, 채용 기획과 운영, 인재 발굴 |
| 육성 | 교육 프로그램 기획, 경력 개발 |
| 평가·보상 | 평가 제도, 급여·성과급 설계 |
| 조직문화·노사 | 조직 진단, 소통 프로그램, 노사 관계 |
| 인사 운영·분석 | 인사 데이터 관리와 분석, 제도 운영 |

### 하루 업무 예시

- 오전: 부서별 인력 수요 조사 결과 정리
- 점심 후: 신입사원 교육 프로그램 기획 회의
- 오후: 직원 설문 데이터 분석으로 조직문화 개선 과제 도출
- 저녁 전: 채용 일정과 운영 계획 점검

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

- 인사 기능 전체 흐름 정리 (채용 → 배치 → 육성 → 평가 → 보상 → 퇴직)
- 반도체 산업의 인재 특성 조사 (기술 인재 비중, 인재 확보 경쟁)

### 2단계: 기본기 (3~4개월)

- 인적자원관리 이론과 실제 기업 사례 비교
- 근로기준법 핵심 내용 정리
- 설문 설계와 기초 통계 분석 실습

### 3단계: 심화 (3~6개월)

- 피플 애널리틱스: 이직, 몰입도 데이터 분석 사례 공부
- 기술 인재 육성 프로그램 사례 조사 (산학 협력, 사내 대학 등)
- 관심 분야 자격증 준비

### 4단계: 포트폴리오 (2~3개월)

- 인사 제도 개선 제안서 또는 데이터 분석 보고서

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 인사 | 인적자원관리 교재 | 기본 |
| 노동법 | 노동법 입문서, 고용노동부 자료 | 법 기초 |
| 데이터 | 공개 인사 데이터셋(이직 예측 등), 통계 입문 | 분석 실습 |
| 트렌드 | HR 관련 연구기관 보고서 | 최신 동향 |

## 5. 직접 해보는 프로젝트

1. **이직 예측 데이터 분석** (기본기): 공개 데이터로 이직 요인 분석
2. **기술 인재 확보 전략 제안서** (심화): 반도체 엔지니어 채용 경쟁 상황 분석과 대안
3. **조직문화 설문 설계** (기본기): 문항 설계, 응답 분석, 개선안 도출

## 6. 자격증·교육 프로그램

- **공인노무사**는 준비 기간이 길지만 강력한 근거가 됩니다.
- **경영지도사(인적자원관리)**, **직업상담사** 등은 보조적인 근거입니다.
- 사회조사분석사는 설문·분석 역량을 보여주는 데 쓸 수 있습니다.

## 7. 자기소개서·면접에서 보여주는 법

- **사람과 원칙 사이에서 판단한 경험**: 공정성과 배려가 부딪힌 상황에서의 선택
- **데이터로 사람 문제를 다룬 경험**
- **면접 단골 질문 대비**: 반도체 회사가 인재를 지키는 방법, 공정한 평가란 무엇인가, MZ세대 조직문화

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "사람 좋아하면 된다" → 제도 설계, 법, 데이터 분석이 핵심인 전문 직무입니다.
- "반도체 기술은 몰라도 된다" → 기술 인재의 일을 이해해야 필요한 인재를 뽑고 기를 수 있습니다.

**지원 전 체크리스트**

- [ ] 인사 기능 전체 흐름을 설명할 수 있다
- [ ] 근로기준법 핵심 내용을 알고 있다
- [ ] 인사·조직 관련 데이터를 분석해 본 경험이 있다
