# S/W개발

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/softwareDev.php>

## 1. 이 직무는 무슨 일을 하나

반도체 회사에서도 소프트웨어 개발자는 매우 많이 필요합니다. **칩을 동작시키는 소프트웨어, 칩을 만드는 공장의 소프트웨어, 반도체로 만든 제품의 소프트웨어**를 모두 개발합니다.

| 분야 | 예시 | 주로 쓰는 기술 |
|---|---|---|
| **펌웨어·임베디드** | SSD 컨트롤러 펌웨어, 모바일 칩의 부트로더 | C, 임베디드 시스템, RTOS |
| **시스템 소프트웨어** | 칩의 드라이버, 운영체제 지원 | C, Linux 커널, 디바이스 드라이버 |
| **설계 자동화·도구** | 설계·검증 자동화 도구, 테스트 프로그램 | Python, C++ |
| **제조 IT·데이터** | 생산 관리 시스템, 장비 제어 SW, 공정 데이터 분석 | Java, Python, 데이터베이스, 클라우드 |
| **AI** | 불량 검출 비전 모델, 공정 최적화, 사내 AI 플랫폼 | Python, PyTorch, MLOps |

### 하루 업무 예시

- 오전: SSD 펌웨어에서 특정 작업 순서일 때만 생기는 버그 재현
- 점심 후: 코드 리뷰, 동료의 변경 사항 검토
- 오후: 성능 측정 결과를 보고 병목 구간 최적화
- 저녁 전: 테스트 자동화 스크립트 개선

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **코딩 기본기와 컴퓨터가 동작하는 원리를 연결한다.**

- 자료구조·알고리즘 기본 문제 꾸준히 풀기
- C로 메모리 할당, 포인터, 구조체 다루기
- Linux 명령어와 Git 기본 사용법

### 2단계: 기본기 (3~4개월)

목표: **운영체제와 컴퓨터구조를 코드로 체험한다.**

- 운영체제 개념(프로세스, 스레드, 동기화, 가상 메모리)을 C로 실습
- 코딩 테스트 대비: 그래프 탐색, 동적 계획법, 구현 문제
- 분야 고르기: 임베디드 / 시스템 / 데이터·AI 중 하나

### 3단계: 심화 (3~6개월)

- 임베디드: 마이크로컨트롤러로 센서 제어, 인터럽트, 통신(UART, SPI, I2C)
- 시스템: 간단한 Linux 커널 모듈이나 디바이스 드라이버 작성
- 스토리지: 파일시스템, NAND 플래시의 특성(지우기 단위, 수명)과 FTL 개념
- 데이터·AI: 공개 제조 데이터로 분석 파이프라인, 이미지 불량 검출 모델

### 4단계: 포트폴리오 (2~3개월)

- GitHub에 README가 잘 정리된 프로젝트 1~2개
- 각 프로젝트에 "문제 → 설계 → 어려웠던 버그와 해결 → 성능 결과" 포함

## 5. 직접 해보는 프로젝트

1. **간이 FTL 시뮬레이터** (심화): NAND의 페이지·블록 구조를 흉내 내고 가비지 컬렉션 정책별 성능 비교
2. **임베디드 센서 시스템** (기본기): 마이크로컨트롤러로 센서 값을 읽어 전송하는 펌웨어
3. **멀티스레드 프로그램 성능 분석** (기본기): 동기화 방식별 성능 비교
4. **웨이퍼 이미지 불량 분류기** (심화): 공개 데이터로 이미지 분류 모델과 간단한 서비스 구성

## 6. 자격증·교육 프로그램

- 삼성의 SW 역량 테스트를 준비하는 지원자가 많습니다. 공식 채용 공고에서 해당 직무의 전형을 꼭 확인하세요.
- **정보처리기사**는 기본기를 정리하는 데 쓸 수 있지만, 실력은 코딩 테스트와 프로젝트로 보여주는 편이 낫습니다.

## 7. 자기소개서·면접에서 보여주는 법

- **"반도체 회사의 SW"라는 점을 이해하고 있음을 보여주기**: 하드웨어 제약(메모리, 실시간성, 전력)을 고려한 경험
- **어려웠던 버그 하나를 깊게**: 증상 → 가설 → 도구 → 원인 → 해결
- **면접 단골 질문 대비**: 프로세스와 스레드의 차이, 데드락, 캐시가 성능에 주는 영향, 메모리 누수 찾는 법

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "반도체 회사 SW는 하드웨어 전공자만 한다" → 컴퓨터 전공자가 핵심 인력입니다. 다만 하드웨어에 대한 관심은 큰 강점입니다.
- "웹 개발 경험은 쓸모없다" → 제조 IT, 사내 플랫폼 분야에서는 웹·서버 경험도 활용됩니다.
