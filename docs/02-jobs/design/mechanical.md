# 기구개발

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/instrumentDev.php>

## 1. 이 직무는 무슨 일을 하나

반도체를 만드는 **장비와 자동화 시스템의 기계적인 부분을 설계·개발하는 일**입니다. 반도체 공장(팹)은 나노미터 단위의 정밀도가 필요하고, 웨이퍼를 사람이 아닌 장비와 로봇이 옮깁니다. 그래서 정밀 기구, 진동 제어, 열·유체 관리, 물류 자동화가 모두 이 직무의 영역입니다.

| 분야 | 다루는 것 |
|---|---|
| **정밀·광학 기구** | 노광·계측 장비의 광학 부품을 정밀하게 잡고 움직이는 구조 |
| **진동·소음** | 미세한 진동이 공정에 영향을 주지 않도록 줄이는 설계 |
| **열·유체** | 장비 안의 온도 균일도, 가스·냉각수 흐름 |
| **구동·제어** | 모터, 스테이지, 로봇의 움직임과 제어 |
| **물류 자동화** | 웨이퍼 운반 시스템(천장 반송 장치 등), 공장 내 로봇 |

### 하루 업무 예시

- 오전: 새 반송 로봇의 진동 측정 결과 분석
- 점심 후: 3D CAD로 부품 설계 수정, 공차 검토
- 오후: 열유동 해석으로 장비 내부 온도 분포 확인
- 저녁 전: 시제품 조립 현장에서 문제점 확인

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **반도체 공장에서 기계가 하는 역할을 이해한다.**

- 반도체 8대 공정과 각 공정 장비의 기본 구조 조사
- 팹 물류 자동화(웨이퍼 운반 용기, 천장 반송 장치) 개념 정리

### 2단계: 기본기 (3~4개월)

목표: **4대 역학을 설계에 연결한다.**

- 3D CAD로 간단한 스테이지나 그리퍼 설계
- 구조 해석으로 처짐과 고유진동수 확인
- 기계진동: 1자유도 진동계, 공진 회피 설계

### 3단계: 심화 (3~6개월)

목표: **한 분야를 골라 "설계 → 해석 → 제작 → 측정"을 끝까지 해 본다.**

- 구동·제어: 모터와 엔코더로 위치 제어 시스템 제작, PID 튜닝
- 열·유체: 냉각 구조 설계와 열유동 해석, 실험 비교
- 진동: 가속도 센서로 진동 측정, 방진 구조 효과 비교

### 4단계: 포트폴리오 (2~3개월)

- 캡스톤 디자인이나 개인 프로젝트를 "요구사항 → 설계안 비교 → 해석 → 제작 → 시험 결과" 순서로 정리
- 도면, 해석 이미지, 시험 데이터를 함께 담기

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 역학 | 학부 4대 역학 교재, KOCW 강의 | 기본 |
| 진동·제어 | 학부 기계진동, 제어공학 교재 | PID, 주파수 응답 |
| CAD | 학생용 무료 라이선스를 제공하는 3D CAD 도구, FreeCAD | 무료 사용 가능한 것 위주 |
| 해석 | 오픈소스 FEM·CFD 도구 (Elmer, OpenFOAM 등) | 무료 |
| 제어 실습 | Arduino, 라즈베리파이 | 저렴한 하드웨어로 실습 |

## 5. 직접 해보는 프로젝트

1. **1축 정밀 스테이지** (심화): 모터, 리드스크루, 엔코더로 위치 제어, 정밀도 측정
2. **방진 구조 비교 실험** (기본기): 스마트폰 가속도 센서로 진동 측정, 구조별 감쇠 비교
3. **웨이퍼 운반 그리퍼 설계** (기본기): CAD 설계와 구조 해석
4. **장비 냉각 구조 열유동 해석** (심화): 냉각 채널 형상별 온도 균일도 비교

## 6. 자격증·교육 프로그램

- **일반기계기사**: 기계 전공 기본기를 정리하는 데 도움이 됩니다.
- CAD·CAE 교육 수료, 공모전(로봇, 메카트로닉스) 경험도 좋은 근거가 됩니다.

## 7. 자기소개서·면접에서 보여주는 법

- **"만들고 측정해 본" 경험 강조**: 해석만이 아니라 실제로 만들어 확인한 경험
- **설계 선택의 이유**: 여러 안 중에서 왜 이 구조를 골랐는지 비교 근거
- **면접 단골 질문 대비**: 공진을 피하는 방법, 열팽창이 정밀 기구에 주는 영향, PID 각 항의 역할

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "반도체 회사에는 기계 전공 자리가 적다" → 장비, 자동화, 인프라, 패키지 등 기계 지식이 필요한 영역이 넓습니다.
- "CAD만 잘하면 된다" → 왜 그렇게 설계했는지 역학으로 설명할 수 있어야 합니다.

**지원 전 체크리스트**

- [ ] 반도체 공정 장비 하나의 구조를 설명할 수 있다
- [ ] 3D CAD로 설계하고 해석까지 해 본 프로젝트가 있다
- [ ] 진동이나 제어 개념을 실제 사례로 설명할 수 있다
- [ ] 직접 만들어 측정해 본 경험이 있다
