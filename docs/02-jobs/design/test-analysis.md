# 평가 및 분석

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/analysis.php>

## 1. 이 직무는 무슨 일을 하나

만들어진 칩과 공정이 **정말 사양대로 동작하는지 확인하고, 아니라면 왜 그런지 찾아내는 일**입니다. 설계가 "이렇게 동작할 것이다"라고 예측한다면, 평가 및 분석은 "실제로 이렇게 동작했다"를 데이터로 증명합니다.

일은 크게 세 갈래입니다.

| 갈래 | 하는 일 | 예시 |
|---|---|---|
| **제품 평가** | 칩의 전기적 특성과 기능을 측정하고 검증 | 속도·전력·전압 마진 측정, 테스트 프로그램 개발 |
| **불량·물성 분석** | 불량이 난 칩이나 웨이퍼에서 원인을 찾아냄 | 단면을 잘라 전자현미경으로 관찰, 성분 분석 |
| **신뢰성·품질** | 오래 써도, 극한 환경에서도 괜찮은지 확인 | 고온·고전압 가속 수명 시험, 고객 품질 대응 |

최근에는 측정 데이터가 매우 많아서, **데이터 분석으로 불량 패턴을 찾는 능력**이 점점 중요해지고 있습니다.

### 하루 업무 예시

- 오전: 밤새 돌린 테스트 결과에서 특정 웨이퍼 영역에 불량이 몰린 것을 발견
- 점심 후: 불량 칩을 분석팀에 의뢰하고, 공정 이력 데이터와 불량 위치를 겹쳐 보며 원인 후보 정리
- 오후: 설계팀과 회의. 특정 전압 조건에서만 실패하는 현상이 회로 문제인지 공정 문제인지 논의
- 저녁 전: 신뢰성 시험 일정과 판정 기준 정리

## 2. 필요한 역량 지도

| 구분 | 역량 | 어느 정도까지 |
|---|---|---|
| 전공지식 | 반도체소자, 반도체공정 | 소자가 왜 고장 나는지(누설, 산화막 파괴, 전자 이동 등) 물리적으로 설명할 수 있을 것 |
| 전공지식 | 전자회로, 디지털논리 | 측정 결과를 회로 동작과 연결해 해석할 수 있을 것 |
| 전공지식 | 확률·통계 | 분포, 가설검정, 실험계획법(DOE)의 기본 개념 |
| 전공지식 | 재료분석 (분석 지망 시) | SEM, TEM, XPS 같은 분석 장비가 무엇을 보여주는지 |
| 툴·실무 스킬 | Python(pandas, matplotlib) 또는 R | 대량 측정 데이터를 정리하고 시각화 |
| 툴·실무 스킬 | 계측 장비 | 오실로스코프, 파라미터 분석기 등을 실험에서 써 본 경험 |
| 소프트 스킬 | 가설 사고 | "이럴 것이다 → 확인 → 다음 가설" 순서로 원인을 좁혀 가는 습관 |
| 소프트 스킬 | 설명 능력 | 설계·공정 담당자에게 근거를 들어 문제를 설명 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **반도체가 어떻게 만들어지고, 어디서 고장이 날 수 있는지 큰 그림을 잡는다.**

- 반도체 8대 공정 흐름 정리 (웨이퍼 → 산화 → 포토 → 식각 → 증착 → 금속배선 → 테스트 → 패키지)
- MOSFET 구조와 주요 전기적 특성(문턱전압, 누설전류) 정리
- 기초 통계 복습: 평균, 표준편차, 정규분포, 상관관계

### 2단계: 기본기 (3~4개월)

목표: **측정 데이터를 받아서 의미 있는 결론을 낼 수 있다.**

- Python으로 공개 데이터셋(예: 제조 공정 센서 데이터, 웨이퍼맵 데이터)을 분석
    - 분포 그리기, 이상치 찾기, 그룹별 비교
- 실험계획법(DOE) 기초: 요인, 수준, 교호작용
- 고장 메커니즘 공부: 산화막 파괴(TDDB), 전자 이동(EM), 핫캐리어(HCI), 온도 의존성

### 3단계: 심화 (3~6개월)

목표: **한 갈래를 골라 실제 문제를 끝까지 분석해 본다.**

- 제품 평가 지망: 테스트 프로그램의 원리(무엇을, 어떤 조건에서, 어떤 순서로 측정하나), 쉬무 플롯(Shmoo plot) 읽는 법
- 불량 분석 지망: 분석 장비별 원리와 한계, 시료 준비 방법, 학교 공동기기원 교육 수강
- 신뢰성 지망: 가속 수명 시험과 아레니우스 모델, 와이블 분포
- 공통: 머신러닝 기초(분류, 이상 탐지)로 불량 예측 모델 만들어 보기

### 4단계: 포트폴리오 (2~3개월)

- 분석 프로젝트 하나를 "문제 정의 → 가설 → 데이터·실험 → 결론 → 한계" 구조의 보고서로 정리
- 그래프 하나하나에 "이 그래프에서 무엇을 알 수 있는가"를 한 줄씩 붙이기

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 소자 | 학부 반도체소자 교재 (예: Neamen, *Semiconductor Physics and Devices*) | 고장 원리 이해의 기본 |
| 신뢰성 | 반도체 신뢰성 관련 학부·대학원 강의 (KOCW 검색) | 고장 메커니즘 정리 |
| 통계 | 실험계획법·통계적 품질관리 교재 | DOE, 관리도 |
| 데이터 | Python pandas 공식 튜토리얼, Kaggle의 제조 데이터셋 | 실습 위주 |
| 분석 장비 | 대학 공동기기원, 나노종합기술원 등의 장비 교육 | 실제 장비를 만져 볼 기회 |

## 5. 직접 해보는 프로젝트

1. **웨이퍼맵 불량 패턴 분류** (기본기): 공개 웨이퍼맵 데이터로 불량 패턴(가장자리, 중앙, 긁힘 등)을 분류하는 모델 만들기
2. **소자 특성 측정 실험 보고서** (기본기): 학교 실험에서 측정한 MOSFET I-V 곡선으로 문턱전압 추출, 온도별 변화 분석
3. **DOE로 공정 조건 최적화** (심화): 가상의 공정 변수 3개로 실험 설계를 짜고 결과를 분석
4. **신뢰성 수명 예측** (심화): 가속 시험 데이터(공개 자료나 가상 데이터)로 와이블 분석과 수명 추정

## 6. 자격증·교육 프로그램

- **품질경영기사**: 통계적 품질관리 개념을 정리하는 데 도움이 됩니다. 필수는 아닙니다.
- **반도체 공정·분석 실습 교육**: 대학·지자체 반도체 아카데미, 나노팹 실습 교육
- **데이터 분석 역량 증명**: 자격증보다는 분석 프로젝트 저장소가 더 설득력이 있습니다.

## 7. 자기소개서·면접에서 보여주는 법

- **"원인을 좁혀 간 과정"을 보여주기**: 결과보다 "어떤 가설을 세웠고, 어떤 데이터로 기각했는지"가 핵심입니다.
- **데이터로 말하기**: "많이 개선됐다"가 아니라 "불량률이 3%에서 1%로 줄었다"
- **면접 단골 질문 대비**: 반도체 고장 메커니즘 2~3가지, 수율이란 무엇이고 왜 떨어지는가, 통계적으로 유의하다는 말의 뜻

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "평가는 단순 반복 측정이다" → 무엇을, 어떤 조건에서 측정할지 정하는 것부터가 설계에 가까운 일입니다.
- "데이터 분석만 잘하면 된다" → 숫자 뒤의 물리 현상을 이해해야 진짜 원인에 도달합니다.
