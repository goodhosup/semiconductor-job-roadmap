# 반도체공정설계

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/semiProcess_design.php>

## 1. 이 직무는 무슨 일을 하나

반도체 한 개를 만들려면 수백 단계의 공정을 거칩니다. 반도체공정설계는 **어떤 공정을 어떤 순서와 조건으로 쌓아야 원하는 소자 성능이 나오는지 전체 흐름을 설계하는 일**입니다. 흔히 PI(Process Integration)라고 부르는 영역이 여기에 해당합니다.

공정기술이 "식각" "증착" 같은 단위 공정 하나를 깊게 다룬다면, 공정설계는 **단위 공정들을 엮어 하나의 제품을 완성**합니다. 공식 소개에서는 소자, 레이아웃, 마스크 개발까지 함께 언급합니다.

| 하는 일 | 설명 |
|---|---|
| 공정 흐름 설계 | 수백 개 공정 단계의 순서와 목표 사양 정하기 |
| 소자 개발 | 트랜지스터·셀 구조를 정하고 전기적 특성 확보 |
| 레이아웃·마스크 | 회로 패턴이 공정에서 제대로 구현되도록 규칙(디자인 룰)과 마스크 설계 |
| 수율·특성 개선 | 전기적 특성 데이터와 불량 데이터를 보고 공정 조건 조정 |

![Planar, FinFET, GAA 트랜지스터 구조](../../assets/figures/transistor-structures.svg)

### 하루 업무 예시

- 오전: 새로 나온 웨이퍼의 전기적 특성(문턱전압, 누설) 데이터 확인
- 점심 후: 특성이 목표에서 벗어난 원인을 찾기 위해 식각·증착 담당자와 회의
- 오후: 다음 시험 생산 웨이퍼의 공정 조건 분할(스플릿) 계획 작성
- 저녁 전: 수율 저하 구간의 단면 분석 결과 검토

## 2. 필요한 역량 지도

| 구분 | 역량 | 어느 정도까지 |
|---|---|---|
| 전공지식 | 반도체소자 | MOSFET 특성이 구조·도핑에 따라 어떻게 바뀌는지 설명 |
| 전공지식 | 반도체공정 | 8대 공정 각각의 원리와 서로의 영향 |
| 전공지식 | 메모리·로직 소자 구조 | DRAM 셀, NAND 셀, FinFET·GAA 구조 |
| 전공지식 | 통계 | 공정 변동과 분포, 실험계획법 |
| 툴·실무 스킬 | 데이터 분석 (Python, JMP 등) | 웨이퍼 데이터를 정리해 원인 찾기 |
| 툴·실무 스킬 | TCAD 기초 (선택) | 공정 변화가 소자에 주는 영향 예측 |
| 소프트 스킬 | 조율 능력 | 여러 공정 담당자와 목표를 맞추고 결정을 이끄는 능력 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **8대 공정과 소자 동작의 큰 그림을 연결한다.**

- 8대 공정 흐름 정리
- MOSFET 구조, 문턱전압, 단채널 효과

### 2단계: 기본기 (3~4개월)

목표: **"이 공정을 바꾸면 소자가 어떻게 변하는가"를 설명할 수 있다.**

- 공정 변수(산화막 두께, 도핑 농도, 게이트 길이)와 소자 특성의 관계 정리
- DRAM·NAND·로직 트랜지스터의 구조와 제조 흐름 비교
- 공정 변동과 수율의 관계

### 3단계: 심화 (3~6개월)

목표: **미세화의 한계와 해결 방법을 이해한다.**

- FinFET에서 GAA로 가는 이유, 고유전율(High-k) 게이트, EUV 노광
- DRAM 커패시터 미세화, NAND 고적층의 공정 과제
- 학회 발표 자료나 논문으로 최신 소자 구조 공부
- 가능하면 학교 나노팹에서 MOS 커패시터나 트랜지스터 제작 실습

### 4단계: 포트폴리오 (2~3개월)

- 소자 제작 실습 보고서: 공정 흐름도, 측정 결과, 이론과의 차이 분석
- 미세화 기술 하나를 깊게 다룬 기술 리뷰

## 5. 직접 해보는 프로젝트

1. **공정 흐름도 그리기** (입문): CMOS 인버터를 만드는 전체 공정을 단면 그림으로 순서대로
2. **MOS 커패시터 제작·측정** (심화): C-V 측정으로 산화막 두께와 계면 특성 추출
3. **공정 변수 민감도 분석** (기본기): 교과서 수식이나 TCAD로 문턱전압의 변수별 민감도 계산
4. **미세화 기술 리뷰** (심화): GAA, 고적층 NAND 등 한 주제의 과제와 해결책 정리

## 6. 자격증·교육 프로그램

자격증보다 **공정 실습 경험**이 가장 강력한 근거입니다. 대학·지자체·정부 지원 반도체 공정 실습 교육을 적극 활용하세요.

## 7. 자기소개서·면접에서 보여주는 법

- **"공정과 소자를 연결해 생각한다"를 보여주기**: 공정 하나를 바꿨을 때 소자 특성이 어떻게 바뀌는지 설명
- **실습 경험이 있다면 실패담까지**: 예상과 다른 결과가 나왔을 때 원인을 어떻게 찾았는가
- **면접 단골 질문 대비**: 단채널 효과와 해결법, FinFET과 GAA의 차이, DRAM과 NAND의 구조 차이

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "공정설계는 공정기술과 같다" → 공정기술은 단위 공정 하나를 깊게, 공정설계는 전체 흐름과 소자 특성을 책임집니다.
- "전자공학 전공만 유리하다" → 재료, 화학, 물리 전공도 많이 지원합니다. 소자 물리를 잘 아는 것이 핵심입니다.

**지원 전 체크리스트**

- [ ] 8대 공정 흐름을 단면 그림으로 그릴 수 있다
- [ ] 공정 변수와 소자 특성의 관계를 예로 들 수 있다
- [ ] 미세화 기술 하나(GAA, 고적층 등)를 깊게 설명할 수 있다
- [ ] 공정 실습이나 소자 측정 경험이 있다
