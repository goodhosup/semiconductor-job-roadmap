# 생산관리

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/productionManagement.php>

## 1. 이 직무는 무슨 일을 하나

**무엇을, 언제, 얼마나 만들지 계획하고, 그 계획대로 공장이 돌아가도록 관리하는 일**입니다. 반도체는 웨이퍼 한 장이 완성되기까지 몇 주에서 몇 달이 걸리기 때문에, 수요 예측과 생산 계획이 회사 실적에 직접 영향을 줍니다.

| 하는 일 | 설명 |
|---|---|
| 생산 계획 | 수요 예측과 재고를 보고 제품별 생산량 결정 |
| 생산성 관리 | 공정 흐름, 장비 가동, 생산 기간(사이클 타임) 관리 |
| 공급망(SCM) | 원자재 조달부터 고객 납품까지 흐름 관리 |
| 외부 협력사 관리 | 파운드리·외주 조립테스트(OSAT) 업체와 생산 일정 조율 |
| 시스템 구축 | 계획·관리를 자동화하는 시스템 기획과 개선 |

### 하루 업무 예시

- 오전: 지난주 생산 실적과 계획 차이 분석
- 점심 후: 영업팀의 수요 변경을 반영한 다음 달 생산 계획 수정
- 오후: 병목 공정의 대기 시간을 줄이기 위한 투입 순서 조정 검토
- 저녁 전: 공급망 이슈(원자재 지연) 대응 회의

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **반도체 공급망 전체를 그림으로 그릴 수 있다.**

- 반도체 가치사슬: 설계 → 웨이퍼 제조 → 조립·테스트 → 고객
- 반도체 경기 사이클과 재고의 관계

### 2단계: 기본기 (3~4개월)

목표: **생산관리의 기본 모델을 직접 풀어 본다.**

- 선형계획법으로 제품 생산량 최적화 문제 풀기 (Python의 최적화 라이브러리 활용)
- 리틀의 법칙(재공 재고 = 처리율 × 사이클 타임) 이해
- 수요 예측: 이동평균, 지수평활, 간단한 회귀

### 3단계: 심화 (3~6개월)

목표: **실제 같은 복잡한 상황을 모델링한다.**

- 이산사건 시뮬레이션으로 가상의 반도체 공정 라인 모델링, 병목 분석
- 공급망 리스크 사례 연구 (반도체 공급 부족 사례 등)
- 데이터베이스와 SQL로 생산 데이터 다루기

### 4단계: 포트폴리오 (2~3개월)

- "문제 정의 → 모델 → 결과 → 의사결정 제안" 형태의 분석 보고서

## 5. 직접 해보는 프로젝트

1. **생산 믹스 최적화** (기본기): 제품 3개, 장비 제약이 있는 상황에서 이익 최대화
2. **수요 예측 모델 비교** (기본기): 공개 판매 데이터로 예측 방법 비교
3. **반도체 라인 시뮬레이션** (심화): SimPy로 공정 단계와 장비를 모델링해 병목과 사이클 타임 분석
4. **공급망 리스크 사례 분석** (심화): 실제 사례를 조사하고 대응 전략 제안
