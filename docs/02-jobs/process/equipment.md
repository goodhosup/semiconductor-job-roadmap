# 설비기술

> 확인 기준일: 2026-10-28 · 공식 직무소개: <https://www.samsung-dsrecruit.com/recruits/job_intro/memory/constructionTech.php>

## 1. 이 직무는 무슨 일을 하나

반도체 공장에는 노광기, 식각 장비, 증착 장비 같은 고가의 장비가 수없이 많습니다. 설비기술은 **이 장비들이 멈추지 않고, 정확하게, 더 빠르게 돌아가도록 운영·유지보수·개조·개선하는 일**입니다.

| 하는 일 | 설명 |
|---|---|
| 운영·유지보수 | 장비 상태 점검, 정기 보수(PM), 고장 대응 |
| 성능 향상 | 장비 가동률과 처리량을 높이는 개선 |
| 개조·개선 | 부품·구조를 바꿔 장비 성능이나 신뢰성 개선 |
| 신규 장비 셋업 | 새 장비 도입 시 설치와 안정화 |
| 데이터 기반 관리 | 장비 센서 데이터로 고장을 미리 예측 |

설비기술과 공정기술은 짝처럼 일합니다. 공정기술이 "어떤 조건으로 만들까"를 정한다면, 설비기술은 "장비가 그 조건을 정확히 구현하게" 만듭니다.

### 하루 업무 예시

- 오전: 장비별 가동 현황과 경보 이력 확인
- 점심 후: 진공 펌프 이상으로 멈춘 장비의 원인 분석과 부품 교체 조치
- 오후: 장비 센서 데이터로 정기 보수 주기 최적화 분석
- 저녁 전: 장비 협력사 엔지니어와 개선안 논의

## 2. 필요한 역량 지도

| 구분 | 역량 | 어느 정도까지 |
|---|---|---|
| 전공지식 | 전기·전자 (회로, 전력, 센서) | 장비 전원과 제어 회로 이해 |
| 전공지식 | 기계 (열유체, 동역학) | 진공, 냉각, 구동부 이해 |
| 전공지식 | 제어공학, 자동화 | PLC, 시퀀스 제어, 피드백 제어 개념 |
| 전공지식 | 진공·플라즈마 기초 | 진공 펌프, 압력 측정, RF 전원 |
| 툴·실무 스킬 | 데이터 분석 | 장비 로그로 이상 패턴 찾기 |
| 툴·실무 스킬 | 계측 장비 | 멀티미터, 오실로스코프 사용 |
| 소프트 스킬 | 문제 해결 끈기, 협업 | 공정·협력사와 함께 원인을 끝까지 추적 |

## 3. 학습 로드맵

### 1단계: 입문 (1~2개월)

목표: **반도체 장비의 기본 구조를 그릴 수 있다.**

- 8대 공정별 대표 장비의 구조 조사 (챔버, 진공 시스템, 가스 공급, 전원, 반송부)
- 진공의 기본: 압력 단위, 펌프 종류

### 2단계: 기본기 (3~4개월)

목표: **장비를 구성하는 요소 기술을 이해한다.**

- 전기: 전력 변환, 모터 드라이브, 센서
- 제어: PLC 기초, 시퀀스 제어, PID
- 플라즈마 장비의 RF 전원과 임피던스 매칭 개념

### 3단계: 심화 (3~6개월)

목표: **"고장 → 원인 → 조치 → 재발 방지"를 체계적으로 다룬다.**

- 고장 분석 기법: FMEA, 근본 원인 분석(5 Why, 특성요인도)
- 설비 종합 효율(OEE)과 예지 보전 개념
- 센서 데이터로 이상 탐지 모델 만들어 보기

### 4단계: 포트폴리오 (2~3개월)

- 직접 만들거나 고친 장치·자동화 시스템 사례 정리
- 데이터 기반 고장 예측 프로젝트 정리

## 4. 추천 학습 자료

| 분야 | 자료 | 비고 |
|---|---|---|
| 장비 개론 | 반도체 장비 입문서, 장비 기업 기술 자료 | 구조 이해 |
| 진공 | 진공 기술 입문 교재 | 펌프, 압력 |
| 제어 | PLC 입문 교재, 자동화 실습 교육 | 시퀀스 제어 |
| 데이터 | 공개 설비 고장 예측 데이터셋 | 예지 보전 실습 |
| 교육 | 반도체 장비 실습 교육, 폴리텍·아카데미 과정 | 실제 장비 경험 |

## 5. 직접 해보는 프로젝트

1. **장비 구조 분석 노트** (입문): 식각 장비 하나를 하위 시스템별로 정리
2. **PLC·마이크로컨트롤러 자동화 장치** (기본기): 센서와 액추에이터로 간단한 자동 시퀀스 구현
3. **예지 보전 모델** (심화): 공개 설비 센서 데이터로 고장 예측
4. **FMEA 작성 연습** (기본기): 가상의 진공 시스템 고장 모드와 대책 정리

## 6. 자격증·교육 프로그램

- **전기기사**, **일반기계기사**, **전자기사** 등은 전공 기본기를 보여주는 데 도움이 될 수 있습니다.
- 장비 실습 교육과 자동화 교육 수료도 좋은 근거가 됩니다.

## 7. 자기소개서·면접에서 보여주는 법

- **고쳐 본 경험**: 무엇이 고장 났고, 어떻게 원인을 찾았고, 재발을 어떻게 막았는지
- **전기·기계를 넘나드는 사고**: 한 분야에 머물지 않고 시스템 전체를 보는 시각
- **면접 단골 질문 대비**: 진공이 필요한 이유, 플라즈마 장비의 구성, 설비 가동률을 높이는 방법

## 8. 흔한 오해와 체크리스트

**흔한 오해**

- "설비는 단순 정비다" → 장비 성능 개선과 데이터 기반 관리까지 포함하는 엔지니어링 직무입니다.
- "한 전공만 필요하다" → 전기, 전자, 기계, 제어 지식을 모두 쓰는 융합 직무입니다.

**지원 전 체크리스트**

- [ ] 반도체 장비 하나의 구조를 하위 시스템별로 설명할 수 있다
- [ ] 진공과 플라즈마의 기본 개념을 말할 수 있다
- [ ] 고장 원인을 찾아 해결한 경험이 있다
- [ ] 제어나 자동화를 직접 구현해 본 경험이 있다
