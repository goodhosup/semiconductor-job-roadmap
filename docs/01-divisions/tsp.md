# TSP총괄

> 확인 기준일: 2026-10-28 · 공식 사업부소개: <https://www.samsung-dsrecruit.com/recruits/division_intro/detail/testPackage_center.php>

## 한 줄 요약

**반도체의 후공정, 즉 패키지 제조와 테스트를 책임지는 조직**입니다. 웨이퍼에서 잘라 낸 칩을 쌓고, 연결하고, 보호하고, 검사해서 출하하는 과정을 맡습니다. 미세화가 느려지면서 첨단 패키징이 핵심 경쟁력이 되었다고 소개합니다.

## 무엇을 하나

| 영역 | 하는 일 |
|---|---|
| **패키지 제조** | 칩을 기판에 붙이고 연결하고 밀봉 |
| **테스트** | 출하 전 전기적 특성과 기능 검사 |
| **차세대 기술 개발** | 첨단 패키징과 테스트 기술 |
| **공급망** | 생산 계획, 외주 조립테스트(OSAT) 협력사 관리 |

## 꼭 알아야 할 기술 키워드

| 키워드 | 한 줄 설명 | 왜 중요한가 |
|---|---|---|
| 후공정 | 웨이퍼 이후의 조립·테스트 단계 | 제품의 최종 품질 결정 |
| 첨단 패키징 | 여러 칩을 쌓거나 나란히 붙여 하나처럼 쓰는 기술 | 성능 향상의 새로운 방법 |
| HBM | DRAM을 수직으로 쌓은 고대역폭 메모리 | 패키징 기술이 제품 경쟁력을 좌우 |
| 테스트 | 불량 칩을 걸러 내는 검사 | 고객 품질과 원가에 직결 |
| OSAT | 외주 조립·테스트 전문 기업 | 생산 능력 확보와 원가 관리 |

## 요즘 이슈 읽는 법

1. **HBM과 AI**: AI 가속기 수요가 패키징 기술 수요로 이어지는 흐름
2. **칩렛**: 큰 칩 하나 대신 작은 칩 여러 개를 연결하는 방식
3. **테스트 비용**: 칩이 복잡해질수록 테스트 시간과 비용이 늘어나는 문제
