# CTO 반도체연구소

> 확인 기준일: 2026-10-28 · 공식 사업부소개: <https://www.samsung-dsrecruit.com/recruits/division_intro/detail/cto_semiconductor.php>

## 한 줄 요약

**다음 세대 반도체 기술을 먼저 개발해 사업부에 넘겨주는 선행 연구 조직**입니다. 메모리와 시스템반도체를 모두 연구하며, 연구 결과를 양산 사업부로 이관해 상용화로 연결한다고 소개합니다.

## 무엇을 연구하나

| 분야 | 연구 대상 |
|---|---|
| **메모리** | DRAM, Flash, 차세대 메모리 |
| **시스템반도체** | 로직 트랜지스터, 이미지센서(CIS) |
| **기반 기술** | 포토마스크, 소재, 차세대 패키지 |

연구소 자체 라인과 R&D 인프라로 선행 기술을 검증하고 최적화합니다.

## 꼭 알아야 할 기술 키워드

| 키워드 | 한 줄 설명 | 왜 중요한가 |
|---|---|---|
| 선행 개발 | 양산 몇 세대 전의 기술을 미리 개발 | 미래 경쟁력의 출발점 |
| 기술 이관 | 연구 결과를 양산 라인으로 옮기는 것 | 연구와 양산의 차이를 메우는 과정 |
| 차세대 메모리 | MRAM, PRAM, ReRAM 등 새로운 원리의 메모리 | DRAM·NAND의 한계 보완 |
| 신소재 | 2차원 소재, 새 유전체·금속 소재 | 미세화 한계 돌파 |

## 이 사업부와 연결되는 직무

공식 소개에 나온 직무 기준입니다.

- **[반도체공정설계](../02-jobs/process/process-integration.md)**: 차세대 소자·공정·패키지 연구
- **[반도체공정기술](../02-jobs/process/process-engineering.md)**: 차세대 공정·소재·마스크 연구
- **[설비기술](../02-jobs/process/equipment.md)**: 연구 라인 설비 유지보수와 최적화
- **[CAE시뮬레이션](../02-jobs/design/cae-simulation.md)**: 물리·AI 기반 시뮬레이션으로 특성 예측

## 요즘 이슈 읽는 법

1. **미세화 이후의 길**: 구조(GAA, 3D 적층), 소재, 패키징 중 어디서 돌파구를 찾나
2. **새로운 메모리**: 어떤 원리의 메모리가 연구되고 있고, 어디에 쓰일 수 있나
3. **연구에서 양산까지**: 논문 기술이 실제 제품이 되기까지 걸리는 시간과 과제
