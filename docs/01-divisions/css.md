# CSS사업팀

> 확인 기준일: 2026-10-28 · 공식 사업부소개: <https://www.samsung-dsrecruit.com/recruits/division_intro/detail/css.php>

## 한 줄 요약

**실리콘이 아닌 화합물반도체(GaN, SiC 등)로 마이크로 LED와 전력반도체를 개발하는 조직**입니다. 소재 성장(에피)부터 칩 제작, 패키지와 모듈까지 전 과정을 다룬다고 소개합니다.

## 무엇을 만드나

| 제품·기술 | 설명 | 쓰이는 곳 |
|---|---|---|
| **MicroLED / LEDoS** | 실리콘 위에 아주 작은 LED를 만든 초소형·저전력 디스플레이 | AR 글라스 같은 마이크로 디스플레이 |
| **전력반도체** | 높은 전압과 전류를 효율적으로 다루는 칩 | 전기차 구동·충전, 산업용·소비자용 전원 |
| **화합물반도체 소재** | GaN, SiC 같은 넓은 밴드갭 소재 | 고전압·고효율 소자 |

## 꼭 알아야 할 기술 키워드

| 키워드 | 한 줄 설명 | 왜 중요한가 |
|---|---|---|
| 화합물반도체 | 두 가지 이상 원소로 된 반도체 (GaN, SiC 등) | 실리콘보다 높은 전압·주파수·효율 |
| 넓은 밴드갭 (WBG) | 전자를 움직이는 데 더 큰 에너지가 필요한 성질 | 고전압·고온에서 유리 |
| 에피 성장 | 기판 위에 결정을 한 층씩 키우는 공정 | 소자 품질의 출발점 |
| 마이크로 LED | 매우 작은 LED를 픽셀로 쓰는 디스플레이 | 고휘도·저전력 |
| 전력 변환 효율 | 전기를 바꿀 때 손실을 줄이는 정도 | 전기차 주행 거리, 에너지 절감 |

## 이 사업부와 연결되는 직무

공식 소개에 나온 직무 기준입니다.

- **[반도체공정설계](../02-jobs/process/process-integration.md)**: 물성과 소자 지식으로 소자 설계, 공정, 평가, 분석
- **[반도체공정기술](../02-jobs/process/process-engineering.md)**: 전력반도체·발광 소자의 생산 기반 기술

## 요즘 이슈 읽는 법

1. **전기차와 전력반도체**: 전기차 보급과 충전 인프라가 SiC·GaN 수요에 미치는 영향
2. **AR 기기**: 마이크로 디스플레이 수요와 기술 과제
3. **소재와 수율**: 화합물반도체 기판의 품질과 원가
