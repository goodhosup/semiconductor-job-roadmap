# 메모리사업부

> 확인 기준일: 2026-10-28 · 공식 사업부소개: <https://www.samsung-dsrecruit.com/recruits/division_intro/detail/memory.php>

## 한 줄 요약

데이터를 **저장하는 반도체**를 만드는 곳입니다. 스마트폰, PC, 서버, AI 가속기 등 데이터를 다루는 거의 모든 기기에 메모리사업부의 제품이 들어갑니다.

## 무엇을 만드나

메모리는 크게 두 종류로 나뉩니다. 이 둘의 차이를 설명할 수 있으면 면접에서 기본기를 보여줄 수 있습니다.

| 구분 | DRAM | NAND Flash |
|---|---|---|
| 전원을 끄면 | 데이터가 사라짐 (휘발성) | 데이터가 남음 (비휘발성) |
| 강점 | 매우 빠른 읽기·쓰기 | 큰 용량, 낮은 비트당 가격 |
| 쓰이는 곳 | 시스템의 "작업 공간" (메인 메모리) | 사진·앱·OS를 담는 "창고" (SSD, 모바일 저장장치) |
| 기본 구조 | 트랜지스터 1개 + 커패시터 1개 (1T1C) | 전하를 가두는 셀을 수직으로 쌓은 구조 (V-NAND) |

제품은 쓰임새에 따라 더 세분화됩니다.

- **서버·PC용 DRAM**: DDR 계열 규격
- **모바일 DRAM**: 전력을 적게 쓰도록 만든 LPDDR 계열
- **그래픽용 DRAM**: 대역폭을 높인 GDDR 계열
- **HBM (High Bandwidth Memory)**: DRAM 칩 여러 개를 수직으로 쌓고 관통 전극(TSV)으로 연결해 대역폭을 크게 높인 제품. AI 가속기 수요와 함께 중요해졌습니다.
- **SSD·모바일 스토리지**: NAND에 컨트롤러와 펌웨어를 더한 저장장치 제품

## 꼭 알아야 할 기술 키워드

공부할 때 "정의 → 왜 어려운가 → 어떻게 해결하나" 순서로 정리해 두면 좋습니다.

| 키워드 | 한 줄 설명 | 왜 중요한가 |
|---|---|---|
| 미세화 (Scaling) | 셀을 더 작게 만들어 같은 면적에 더 많이 넣는 것 | DRAM은 셀이 작아질수록 커패시터 용량 확보와 누설 전류 관리가 어려워짐 |
| 적층 (Stacking) | NAND 셀을 위로 쌓아 용량을 늘리는 것 | 단수가 늘수록 깊고 좁은 구멍을 뚫는 식각 공정 난이도가 커짐 |
| TSV / 첨단 패키징 | 칩을 쌓고 수직으로 연결하는 기술 | HBM 성능과 수율을 좌우함 |
| Refresh | DRAM 커패시터의 전하가 새기 전에 주기적으로 다시 써 주는 동작 | 전력 소모와 성능에 직접 영향 |
| 신뢰성 (Endurance, Retention) | 반복해서 써도, 오래 둬도 데이터가 유지되는 능력 | NAND 제품 품질의 핵심 지표 |
| CXL | CPU와 메모리를 새로운 방식으로 연결하는 인터페이스 표준 | 서버 메모리 확장 방식의 변화 |

## 이 사업부와 연결되는 직무

메모리사업부에는 설계부터 제조, 사업까지 여러 직무가 함께 일합니다. 관심 있는 직무 장으로 넘어가 학습 로드맵을 확인하세요.

- **[회로설계](../02-jobs/design/circuit-design.md)**: DRAM·NAND의 셀 주변 회로, 입출력 인터페이스, 전원 회로 설계
- **[평가 및 분석](../02-jobs/design/test-analysis.md)**: 만든 칩이 사양대로 동작하는지 검증하고 불량 원인 분석
- **[S/W개발](../02-jobs/design/software.md)**: SSD 펌웨어, 테스트 자동화, 데이터 분석 도구
- **[반도체공정설계](../02-jobs/process/process-integration.md)**, **[반도체공정기술](../02-jobs/process/process-engineering.md)**: 미세화·적층 구조를 실제 공정으로 구현
- **[패키지개발](../02-jobs/design/package.md)**: HBM 같은 적층 제품의 패키징
- **[영업마케팅](../02-jobs/business/sales-marketing.md)**: 고객사 요구를 제품 계획으로 연결

## 요즘 이슈 읽는 법

메모리 산업은 경기에 따라 가격이 크게 오르내리는 특징이 있습니다. 뉴스를 읽을 때 아래 세 가지를 같이 보면 흐름이 보입니다.

1. **수요처**: 지금 메모리를 가장 많이 사는 곳이 어디인가 (스마트폰, PC, 데이터센터, AI 서버)
2. **제품 세대**: 어떤 규격(DDR, LPDDR, HBM)이 몇 세대째인가
3. **기술 과제**: 미세화, 적층, 패키징 중 어디에서 경쟁하고 있는가

뉴스 한 건을 읽고 위 세 줄로 요약하는 연습을 꾸준히 하면, 면접에서 "관심 있는 기술 이슈"를 물을 때 자기 언어로 답할 수 있습니다.
